## Speaker notes

**1. Freedom CQA**
- Мы команда YaTebyaMognu. Сделали Freedom CQA: проверку каждого разговора оператора, чаты и звонки, RU, KZ, EN.
- По каждому критерию система даёт ответ, реплику-доказательство и балл. Балл считает код, а не модель.

**2. Проблема**
- Вручную в контакт-центрах проверяют 2–5% разговоров (оценки вендоров, независимой цифры нет).
- На брифинге Freedom сказали прямо: людей мало, а один критерий разные проверяющие читают по-разному.
- 64% клиентов боятся AI в поддержке, потому что не доберутся до человека (Gartner). Значит, нужны и автоматическая проверка, и человек с последним словом.

**3. Решение**
- Весь цикл в одной админке: чек-лист → диалоги → оценка → результаты → апелляция → ручная переоценка.
- Чек-лист хранится как данные: поменяли вес, итоги пересчитаны сразу; поменяли критерий, нажали «Сохранить и переоценить».
- Решение проверяющего пересчитывает итог той же функцией, без вызова модели.

**4. Как оценивает**
- Сначала модель выписывает факты диалога, потом отвечает по каждому критерию. 3 прогона, голосование по большинству; если голоса разошлись, карточка пишет «2 из 3 · проверьте».
- Каждая цитата проверяется: реплика должна существовать, текст совпадать. Нет доказательства, нет ответа.
- Баллы, N/A и округление half-up считает код. Грубая ошибка идёт отдельным красным флагом и баллы не снимает.

**5. Точность**
- 95,4% совпадения по 152 ответам на эталонной разметке, 96,4% на отложенной части, 97,3% с двумя слепыми разметчиками. Все 7 грубых ошибок найдены, ложных нет.
- κ 0,96 уже учитывает случайные совпадения, это не просто проценты. Разметчики между собой совпадают на 96,4%, то есть мы на уровне второго внимательного читателя.
- Честно: эталон наш. Настоящий тест: 10 контрольных чатов, они оценены, файл в `results/prod/results.json`.

**6. Живая проверка**
- Можем оценить ваш диалог прямо сейчас: Загрузка диалогов → «Вставить текст» → «Оценить AI-агентом». Около 30 секунд, около $0,006 за чат.
- Новый текст всегда идёт в модель, кэш его не подменяет. Набор SWAP уже оценён и откроется сразу.
- Результаты в формате JSON 1.0 для DEV и контрольного набора, проверены валидатором.

**7. Звонки и AIM**
- Звонки оцениваем той же логикой. Клик по доказательству переносит плеер на нужную секунду. Тон голоса (c09) оценивает Gemini 3.8 Flash по самой записи.
- AIM на стороне клиента сразу говорит, что он AI, и передаёт клиента оператору вместе со всей перепиской. Разговор оператора потом проходит ту же проверку.

**8. Интеграция**
- Фронтенд статический, без сборки, монтируется в один элемент: формат HTML web resource для Dynamics 365.
- `POST /api/evaluate` подключается к любой CRM; результаты в JSON 1.0; повторный запрос берётся из кэша бесплатно.
- Модель заменяемая: open-weight Qwen 3.8 27B на своём сервере дал 94,1% на тех же метках.

**9. Итог**
- Каждый разговор проверен, каждый балл объяснён, последнее слово за человеком.
- Ссылки на слайде: продукт, админка с кодом `freedom-agent`, репозиторий. Готовы к вопросам и к живой оценке.
