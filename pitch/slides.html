Как оценивает

Модель выбирает ответ и реплику. Баллы считает код.

1

Сначала факты

Запрос, проверка личности, раскрытие данных, как закончился чат. Потом вердикт.

2

3 прогона и голосование

Большинство по каждому критерию. Карточка пишет «3 из 3» или «2 из 3 · проверьте».

3

Цитата проверена

Реплика существует, цитата совпадает. Нет доказательства: повторный запрос, а не выдуманный ответ.

4

Баллы считает код

Вес, шкала, перераспределение N/A, округление half-up до 2 знаков. Одна функция для UI, API и выгрузки.

!

Грубая ошибка отдельно

Красный флаг с репликой. Баллы не снимает, диалог попадает в список на разбор.

Живой запрос к API: C3 = N/A, вес 20 выпадает; C7 = «нет», минус 5.
75 из 80 применимых → 93,75

Интеграция с Freedom

Встраивается в контур Freedom

Dynamics 365

Спроектировано как HTML web resource: статические HTML, CSS и JS без сборки, монтируется в один элемент #cqa-root.

Чек-лист как данные

Критерии, веса, шкалы и правила N/A хранятся в JSON. Руководитель QA меняет их в интерфейсе.

API для любой CRM

POST /api/evaluate: на вход диалог и чек-лист, на выход ответы, объяснения и доказательства.

Формат JSON 1.0

Выгрузка результатов и независимый валидатор: все 8 критериев, номера реплик, пересчёт итога.

Кэш и Redis

Ключ кэша: модель, промпт, диалог, чек-лист. Повторный запрос бесплатен, общий кэш в Upstash Redis.

Своя модель

Любой OpenAI-совместимый сервер через local:<model>. Qwen 3.8 27B с открытыми весами: 94,1% на тех же метках.
